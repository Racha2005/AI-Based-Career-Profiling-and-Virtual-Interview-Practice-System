# 📖 Abstract

MockMate AI is an intelligent AI-powered interview preparation and career guidance platform designed to help students, freshers, and job seekers improve their interview performance and career readiness. The system provides a realistic interview environment by integrating Resume Analysis, Career Profiling, Voice-Based Interviews, Text-Based Interviews, AI-Powered Feedback, Dashboard Analytics, and Career Guidance into a single platform.

Users can upload resumes, automatically extract skills and technologies using Natural Language Processing (NLP), attend personalized mock interviews, receive detailed feedback reports, and continuously monitor their progress through a performance dashboard. The platform bridges the gap between theoretical learning and practical interview experience while helping users build confidence, communication skills, and career awareness.

The project leverages modern technologies such as React.js, FastAPI, PostgreSQL, OpenAI GPT, OpenCV, Speech Processing, JWT Authentication, and bcrypt Security to create a scalable, secure, and user-friendly system.
